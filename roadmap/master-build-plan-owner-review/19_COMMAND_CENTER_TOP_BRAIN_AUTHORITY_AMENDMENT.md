# Command Center — Top Brain Authority Amendment

**Owner:** James Morgan  
**Effective date:** 2026-10-24  
**Status:** CURRENT CONTROLLING ARCHITECTURE AMENDMENT  
**Applies to:** Specification Lock v2.1 and all current/future Command Center ecosystem architecture

## Owner directive

James Morgan explicitly directed:

> **“command center is the top brain and always in charge of all other brains”**

This amendment records that directive durably without rewriting the immutable historical Specification Lock v2 baseline.

## Controlling invariant

**Command Center is the top Brain, highest-level orchestrator, and authoritative control plane for the entire ecosystem.**

Every other Brain, Agent, specialist reasoning system, company intelligence layer, domain-specific AI system, automation system, and future intelligence component is subordinate to Command Center.

No other Brain or system may become a peer control plane to Command Center or override Command Center's final orchestration/governance authority.

## Subordinate intelligence rule

Subordinate Brains may:

- perform deep domain reasoning;
- maintain domain-specific context and models within authorized scope;
- make recommendations;
- execute delegated work within explicitly granted authority;
- own domain-specific truth where the architecture assigns that truth to them;
- specialize independently without forcing one universal reasoning model.

They may **not**:

- overrule Command Center;
- bypass Command Center governance or policy;
- expand their own permissions, company/project/account/environment scope, budget, delegation depth, or protected-action authority;
- reinterpret evidence state to fabricate success;
- modify Command Center's owner authority, roadmap authority, protected-action gates, or portfolio control rules;
- become an independent top-level orchestrator outside Command Center's control.

## Named-system clarification

- **ARO** remains a separate high-intelligence reasoning/specialist system. Its name is exactly **ARO**. ARO is subordinate to Command Center.
- **VeloClip** may own a domain-specific media/content Brain. That Brain is subordinate to Command Center.
- **Coupon AutoPilot** may own a domain-specific savings/deal/shopping Brain. That Brain is subordinate to Command Center.
- **Loopwren** and any other specialist orchestration/intelligence layer remain subordinate to Command Center.
- Future company/domain Brains inherit this same relationship automatically unless James Morgan explicitly changes the architecture.

## Truth ownership versus control authority

Being subordinate to Command Center does **not** mean Command Center duplicates every specialist's private data or domain truth.

The architecture continues to preserve:

- company/customer isolation;
- specialist truth ownership;
- least-privilege access;
- provenance and evidence boundaries;
- proven-before-share capability reuse;
- pin/fork compatibility;
- private data separation.

Command Center's top-Brain role is the final coordination, governance, routing, validation, conflict-resolution, authorization, and lifecycle authority across those systems.

## Conflict resolution

If an older roadmap, prompt, architecture note, test description, or project document can reasonably be read to imply that ARO or any other Brain is the ecosystem's highest-level Brain/control plane, that interpretation is superseded by this amendment.

The older artifact remains historical evidence; this amendment controls the current meaning.

## Implementation requirement

Future runtime contracts and tests must preserve this hierarchy. In particular:

1. subordinate Brain registration must identify Command Center as controlling orchestrator;
2. delegated actions must remain bounded by Command Center-issued scope/policy;
3. subordinate recommendations cannot mutate canonical authority merely by being generated;
4. conflicts between subordinate Brains must be arbitrated through Command Center-controlled policy/evidence paths;
5. protected actions remain behind Command Center's canonical authorization path;
6. failure or compromise of a subordinate Brain must not transfer top-level authority to that Brain.

**This amendment is current authority and must be inherited by all later build work.**
