## Brain quality invariant

Every company must explicitly determine whether it needs a full specialized brain, domain pack, brain modules, deterministic/rules/optimizer systems, or a hybrid. A brain is not accepted because it has a name; its knowledge, reasoning, planning, prediction, optimization, recommendation, decision, execution-support, memory, evaluation, safety, tool, workflow, integration, failure and versioning requirements must be exhaustively mapped for that company.

Shared Brain Factory components do not erase company-specific intelligence. Reuse is allowed only when fit is verified.

## Proven-before-share invariant

- One company proves a capability only for itself.
- Two independent companies create cross-company evidence.
- Three independent companies create portfolio-reuse evidence.
- Critical shared infrastructure requires three-company proof before broad standardization.
- Prove before share.
- Isolate before proven.
- Reuse proven code only when fit is verified.
- Do not create live multi-company dependency on unfinished infrastructure.
- Fork or rebuild when requirements differ.
- Never break a proven live version merely to satisfy a new company.
- Candidate versions require regression, security, performance, compatibility and rollback discipline.
