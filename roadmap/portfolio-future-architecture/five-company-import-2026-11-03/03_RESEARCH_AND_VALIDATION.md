# Public reference sources, verification gaps and research findings

The package uses the 2026-11-03 research snapshot and GitHub source authority. Official primary documentation takes precedence over marketing claims. The live environment/provider access cannot be assumed from a public API page.

## Official source citations

### Recall

- **CPSC Recalls API** — https://www.cpsc.gov/Recalls/CPSC-Recalls-Application-Program-Interface-API-Information. CPSC provides machine-readable recall notices; source freshness and the exact product identifiers available vary.
- **CPSC Recalls Dataset** — https://www.cpsc.gov/Recalls. CPSC notes weekly recall listings and changing remedy data; product identification is not universal.
- **FDA Enforcement Reports** — https://www.fda.gov/safety/recalls-market-withdrawals-safety-alerts/enforcement-reports. FDA explicitly warns that firms often warn customers before formal report classification; do not claim this API alone gives earliest warning.

### Shipping

- **USPS Developer Portal status** — https://devs.usps.com/status. Tracking API exists but each carrier, account, guarantee and eligibility requires current review; live server status is not a pricing guarantee.

### Books

- **KDP Prepare Your Manuscript** — https://kdp.amazon.com/en_US/help/topic/G202187840. Paperback and hardcover interiors may use same source interior, but cover files differ; exact current specifications must be followed.
- **KDP Trim Bleed Margins** — https://kdp.amazon.com/en_US/help/topic/GVBQ3CMEQW3W2VL6/. Correct trim, bleed and page-dependent gutter are necessary; future retailer changes require revalidation.
- **KDP Paperback Submission Guidelines** — https://kdp.amazon.com/en_US/help/topic/G201857950. KDP provides PDF/font/image requirements and publishing review; file validator cannot guarantee retailer acceptance.

### Website

- **W3C WCAG 2.2** — https://www.w3.org/TR/WCAG22/. Accessibility design and audits do not confer legal certification.
- **FTC Endorsements FAQ** — https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides-what-people-are-asking. Do not fabricate testimonials or reviews, and endorsements/disclosures must be truthful.

### Video

- **YouTube Monetization Original Content** — https://support.google.com/youtube/answer/2490020?hl=en. Video commercial use needs rights to both audio and visual materials; uploading/public availability alone does not grant clipping rights.
- **FFmpeg** — https://ffmpeg.org/. Local open-source media processing framework; licensing must be checked for chosen binary/build and redistribution.
