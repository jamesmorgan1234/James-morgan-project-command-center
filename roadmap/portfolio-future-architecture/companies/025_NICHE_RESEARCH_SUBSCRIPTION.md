# Company 025 — Niche Research Subscription

**Company ID:** `company:future:025`  
**Primary project:** `project:company:future:025`  
**Roadmap version:** `COMPANY-025-v1.0.0`  
**Truth state:** PLANNED  
**Authorization:** roadmap/architecture only; no live opportunity hunting or unauthorized research access.

## Business identity

Purpose: provide deeply maintained intelligence for narrowly defined industries/topics through source-backed reports, data, alerts, searchable archives and APIs.

Problem: high-value niches are underserved by broad news/research products; professionals need curated sources, history, terminology and decision-relevant synthesis.

Value: persistent domain knowledge with provenance, not disposable summaries.

Delivery: subscription briefs/newsletters, research portal, datasets, alerts, custom reports, API, premium analyst workspace, enterprise/private knowledge feed.

## Product tree

Daily/Weekly Intelligence Briefs; Research Database; Source/Document Archive; Trend/Theme Tracker; Industry Data Tables; Company/Entity Profiles; Regulation/Policy Tracker; Pricing/Market Tracker; Competitive Landscape; Forecast/Scenario Reports; Event/Deadline Calendar; Alert Watchlists; Expert/Source Directory; Custom Research; Executive Briefs; Research API/Feed; Premium Historical Archive; Benchmark/Index products; Enterprise Knowledge Pack; Vertical Sub-niches.

## Feature/customer/vertical tree

Features: source registry, provenance/citations, taxonomy, entities, timeline, saved searches, watchlists, alerts, document annotation, confidence, fact/inference separation, cross-source comparison, report versioning, data export/API, team workspaces, accessible/localized outputs.

Customers: operators/executives, investors/researchers where lawful, consultants/agencies, vendors, professional associations, journalists/academics/nonprofits/public sector, enterprise strategy/product teams.

Verticals: any niche with enough recurring information value—specialized software, construction trades, creator economy, ecommerce categories, emerging tech, regulatory domains, supply-chain segments, local industries, publishing/media, cybersecurity subfields. Each niche is a product/pack unless operationally distinct enough for a future spinoff.

## Brain / architecture

Domain Brain should build terminology/entity/source knowledge, detect emerging themes, compare evidence, synthesize with citations and clearly label forecasts/uncertainty. Architecture: source registry, collectors for public/licensed sources, document/search/RAG, entity/knowledge graph, temporal store, structured datasets, rules/alerts, LLM synthesis with citations, forecasting/statistics where data supports.

## Agents

Research Planner, Source Monitor, Document Analyst, Data Collector, Entity/Taxonomy Agent, Trend Analyst, Regulation Analyst, Competitive Analyst, Fact Checker, Citation Agent, Forecast/Scenario Agent, Report Editor, Alert Curator, Archive Librarian.

## Deterministic services

Source fetch/feed; document parser; search/index; entity resolution; taxonomy; snapshot/version; dataset ETL; alert rules; calendar; citation/provenance; report renderer; subscription/entitlement; export/API.

## Workflow

Define niche/questions → source registry/rights → continuous collection → classify/entity-link → verify/provenance → data/time-series update → trend/event detection → cited synthesis → editorial/evaluation gate → publish authorized report/feed → archive/correct/version.

## Integrations / API / data

Public/licensed feeds, government/industry sources, documents/web, data warehouses, BI, RSS/email, calendar, customer knowledge tools. APIs for sources/entities/documents/topics/timelines/data/alerts/reports.

Data moat: long curated source archive, domain ontology, entity graph, reviewed research corpus, proprietary derived datasets/indices and correction history.

## Monetization / distribution

Individual/pro/team subscriptions, premium vertical packs, datasets/API, historical archive, custom research, enterprise/private feeds, reports, benchmark/index licensing. Distribution via niche communities, partnerships, SEO/content, associations, developer/data channels; no marketing execution now.

## Security/legal/privacy

Source rights/licensing, citations, copyright limits, no paywall/access bypass, private customer research isolation, no unsupported claims, corrections/versioning, PII minimization.

## Failure / edge cases

Echo-chamber sources, rumor propagated as fact, source retraction, terminology ambiguity, low-sample forecast, hidden sponsorship, outdated dataset, source conflict. Use source ranking, corroboration, fact/inference labels, correction ledger and confidence.

## Scale / platform / overlap

One niche → portfolio of vertical research products → data/API platform. Overlap #6 data, #13 competitive, #16 regulation, #11 benchmarks. #025 focuses on editorial/domain intelligence subscription.

**BUILD BEFORE FIRST COMPANY:** source/knowledge/data pack interfaces and company isolation.
