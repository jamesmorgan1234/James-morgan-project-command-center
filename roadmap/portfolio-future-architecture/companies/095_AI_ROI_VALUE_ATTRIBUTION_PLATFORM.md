# Company 095 — AI ROI & Value Attribution Platform

**Company ID:** `company:future:095`  
**Primary project:** `project:company:future:095`  
**Roadmap version:** `COMPANY-095-v1.0.0`  
**Truth state:** PLANNED  
**Authorization:** roadmap/architecture only; no budget allocation, purchasing, staffing or financial commitment.

## Business identity
Purpose: measure whether AI models, agents and workflows create verified economic/operational value after all attributable costs, failures and human oversight.

## Product tree
AI Cost Ledger; Use-Case Registry; Baseline Builder; Outcome/Value Registry; Workflow/Agent/Model Attribution; Before/After Analysis; Experiment/A-B Support; Counterfactual/Control Analysis; Labor-Time Capacity Model; Revenue/Retention Attribution; Error/Risk Reduction; Quality/CSAT Attribution; Cycle-Time/Throughput; Failure/Support Cost; ROI/Payback/TCO; Portfolio Dashboard; Budget/Keep-Kill-Expand Recommendations; Forecast/Scenario Planning; Benchmarking; API/SDK; Enterprise/Private Deployment.

## Feature/customer/vertical tree
Features: use case, owner, model/agent/workflow version, baseline period, comparison group, costs (model/infra/API/software/human/implementation/maintenance/failure), outcomes, attribution method/confidence, revenue/savings/capacity/risk values, time horizon, assumptions, verified vs estimated state and evidence.
Customers: enterprises, AI teams, finance/FinOps, CIO/CTO offices, agent platforms, consultancies, SaaS/AI vendors and portfolio operators.
Verticals: support, sales, engineering, finance ops, document automation, research, analytics, marketing, security and internal productivity.

## Brain capability / architecture
Brain may form hypotheses, explain causal uncertainty and recommend experiments; ROI arithmetic is deterministic and causal claims require explicit method/evidence. Architecture: cost/event ledger, use-case/version registry, outcome metrics, baseline/experiment store, attribution models, confidence/assumptions, financial calculator, scenario engine and audit/provenance.

## Agent tree
Cost Analyst; Baseline Agent; Outcome Agent; Attribution Analyst; Experiment Agent; Quality/Risk Agent; Forecast Agent; Portfolio Optimizer; Evidence QA Agent; Executive Brief Agent.

## Deterministic services
Cost aggregation; currency/time normalization; unit economics; ROI/payback/TCO formulas; metric definitions; baseline versioning; experiment randomization refs; confidence intervals where applicable; assumption registry; reconciliation.

## Workflow tree
Register AI use case/version → define objective/metrics/baseline → capture all costs and outcomes → choose attribution method → run experiment/control or observational analysis → calculate verified/estimated value separately → expose uncertainty → recommend keep/kill/expand/test → owner/budget authority decides → continue measurement and detect drift.

## Integrations / API / data
Model gateways, agent control center, usage billing, cloud cost, BI/data warehouse, finance/accounting, CRM/support/product analytics, HR/time systems where lawful, experimentation platforms. Data: costs, usage, outcomes, baselines, experiments, assumptions, calculations and recommendations.

## Monetization / distribution
AI spend/use cases, agents/models/workflows, seats, enterprise/private, API, benchmarking and managed value-assessment. Distribution through AI/FinOps/BI/consulting ecosystems.

## Security/privacy/compliance
Avoid employee surveillance and fabricated savings. Separate capacity from actual cash savings, estimates from verified realized value, correlation from causation and revenue attribution from gross revenue. Sensitive finance/HR data isolated.

## Failure / edge cases
No stable baseline, multiple simultaneous changes, seasonality, selection bias, displaced work rather than eliminated cost, quality degradation hidden by throughput, long-term risk, human oversight shifted elsewhere, model price changes, double-counted value across agents, survivor bias.

## Scale / overlap
Use-case dashboard → enterprise AI portfolio economics → AI capital-allocation intelligence. Overlap #68 model cost routing, #69 billing, #15 BI, Command Center portfolio analytics. #095 owns value attribution.

## Classification
**DESIGN NOW:** cost-center/use-case/model/agent/workflow IDs, actual-vs-estimate truth labels, baseline/assumption/evidence, unit economics and no-double-counting lineage.  
**BUILD NOW:** Command Center portfolio operations must track verified costs/value with distinct actual/estimate/forecast states before 100-company scale.  
**BUILD BEFORE FIRST COMPANY:** portfolio cost/value telemetry and baseline/experiment primitives.  
**COMPANY-SPECIFIC LATER:** commercial customer analytics/benchmarks.  
**SCALE-ONLY:** cross-enterprise benchmarks and advanced causal models.
